Clip file names

Slashes and colons are not allowed.

Keyboard shortcuts

Type them like Ctrl+Shift+t, where Alt is Option and Meta is Command. Avoid keys IINA already uses. Quit and reopen IINA to apply. An invalid entry uses the default.

Frame previews

In and Out sit side by side when previews fit panel width.

JPEG quality runs from 2 to 31. Lower is better.

Keyframe arrows

How far the arrows look for the next keyframe. The wider search runs only if the first finds none. Larger values are slower on files with few keyframes.

Vertical crop export

Used only when Vertical crop is on, because cropping re-encodes the video. Lossless clips keep the original format and quality.

File format Default: mov

Hardware quality applies when Hardware acceleration is on. It runs from 1 to 100, and higher is better. Software CRF applies when it is off. It runs from 0 to 51, and lower is better.

FFmpeg location

Leave blank to use FFmpeg from Homebrew.
